# claude-articles-sample

YouTube チャンネル「ずんだもんの実験道具箱」のシリーズ「Claude の記事を読む」で使った再現サンプルです。回ごとにディレクトリを分けています。

- [`no02/`](no02/) — AI と出した結論、本当に自分で決めた？（Anthropic「How AI agents shape experts' judgment calls」を読む）: 架空の継続率データ、エージェントに持たせたチームの方針2通り、分かれ道を表に出させる1文
- [`no03/`](no03/) — auto memory、書いたら終わりになってない？（Anthropic「The components of agent memory」を読む）: auto memory を見返させる自作のコマンド `/memory-review` の全文と置き方、1回だけ頼む1文
- [`no05/`](no05/) — Claude Code の並列実行、何本も走らせて仕事がかぶる？（Anthropic「Safely scaling multi-agent teams with Claude Fable 5.2」を読む）: 仕事の表を作る1行と取る1文、表を頼む文、試した掲示板と表の依頼文

各ディレクトリの README に手順と実測の時点があります。動画と同じ中身を保つため、サンプル自体は改変しません。
